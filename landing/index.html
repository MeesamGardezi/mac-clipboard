FAQ

maClip requires macOS 13 Ventura or later. It is a native Swift app that uses modern macOS APIs not available in older versions.
Accessibility permission is required to intercept the global ⌘ Shift V shortcut from any app — this is a macOS requirement for all global hotkeys. Screen Recording is required for the Snip tool to capture screen regions. maClip never sends any data anywhere; both permissions are used entirely on-device.
